# HLTC Music Player

Website pemutar musik responsif untuk lagu **HLTC x SO ASU**. Dibuat dengan HTML, CSS, dan JavaScript murni agar ringan serta dapat langsung diterbitkan melalui GitHub Pages.

## Menjalankan lokal

Buka `index.html` di browser, atau jalankan server statis dari folder proyek.

## GitHub Pages

Pada repository GitHub, buka **Settings → Pages**, lalu pilih **Deploy from a branch**, branch `main`, folder `/ (root)`.
